# 系统日志接口

`GET /api/v1/system/logs`，复用当前会话认证，仅管理员可读；个人版默认本机管理员。与工具调用审计 `/logs` 独立。

| 参数 | 说明 |
|---|---|
| category | `exception`（默认，WARN/ERROR）或 `runtime`（INFO） |
| level | 可选 INFO/WARN/ERROR |
| q | 可选关键词，最多 200 字节，匹配内容及属性 |
| from / to | 可选 RFC3339 时间；查询范围自动限制在最近 7 天 |
| cursor | 上页 next_cursor；切换条件需清空 |
| limit | 1–200，默认 50 |

返回 `{items:[{id,time,level,message,attrs}],next_cursor,retention_days:7}`，最新写入记录在前；无更多数据时 next_cursor 为空。400 参数错误；401 未登录；403 无管理员权限；503 日志存储未初始化。时间以 UTC 存储、页面按本地时区显示。日志为服务私有文件，页面不提供任意文件读取或清空接口。

每日 JSONL，运行/异常分文件，单分片 8 MiB；启动时及每小时清理过期文件并压缩边界日期，仅保留最近 7 天记录，查询即时排除已过期数据。目录 0700、文件 0600；凭据属性、Bearer、URL 用户信息及查询参数脱敏。页面每 10 秒刷新，详情/历史分页/页面隐藏时暂停自动刷新。

服务在读取数据库前初始化日志；MCP 启动失败、健康检查异常、自动重连、连接恢复、连接测试失败、后台任务失败及 HTTP 内部异常写入对应日志。新版本开始记录，升级前未记录的历史事件不能补造。进程尚未执行或日志目录本身不可写时，应用无法将失败写入该目录，错误仍输出到标准错误。
