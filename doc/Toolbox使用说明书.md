# Toolbox 使用手册入口

更新日期：2026-10-22。

使用手册已按产品形态拆分，分别包含完整操作步骤：

| 手册 | 适用对象 | 主要内容 |
| --- | --- | --- |
| [个人版使用手册](Toolbox个人版使用手册.md) | 本机独立使用的桌面用户 | 免登录、安装与退出、开机启动、MCP配置、客户端接入、日志、备份升级 |
| [企业 Web 版使用手册](Toolbox企业Web版使用手册.md) | 企业管理员、运维及普通成员 | 部署与配置文件、登录、用户角色、IP策略、MCP管理、软件包发布及备份迁移 |

个人版与企业版数据独立。个人版免登录，企业版采用账号登录与角色授权；两者的Gateway客户端接入均需要Token。请按实际使用版本阅读对应手册。
